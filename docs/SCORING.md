# スコア定義書

**このファイルが唯一の正。** `packages/core/src/scoring/` の実装はここに 1 対 1 で対応する。
配点を変えるときは、**先にこのファイルを更新し、`score_version` を上げてから**実装を直す。

---

## score_version

| version | 期間 | 満点の内訳 | 備考 |
|---|---|---|---|
| `v1-technical` | Phase 1〜 | テクニカル 80 点を 100 点に正規化 | ファンダメンタル / ニュースが未実装 |
| `v2-full` | Phase 1b 以降 | 100 点（下表そのまま） | ニュース分析が入った時点で切り替え |

**版番号は辞書順で新しいものが後になるように付ける**（`v1-technical` < `v2-full`）。
画面と API は「その日にある最新版」を既定で返すが、その判定に `MAX(score_version)` を
使っているため。`v9` を超えるときは `v10` ではなく `v09` → `v10` と桁を揃えること。

`scores_daily.score_version` に必ず記録する。**過去のスコアを再計算で書き換えない。**
配点が変わったら新しい version として並べて入れる。そうしないと
「先月 91 点だった銘柄」が今日の基準で何点だったのか分からなくなる。

### v1-technical の正規化

Phase 1 は `c_fundamental` と `c_news` が `NULL` になる。
埋まっている項目の合計を、埋まっている項目の満点合計で割って 100 倍する。

```
total = round( Σ(埋まっている項目の得点) / Σ(埋まっている項目の満点) × 100 )
      = round( Σ(technical 6項目) / 80 × 100 )
```

**欠損項目を 0 点として扱わない。** 0 点にすると「ニュースが無い銘柄」が
「悪材料のある銘柄」と同じ扱いになる。

## 各項目の算出

すべて **その日の終値時点で確定している情報のみ**を使う。
入力が足りない（ウォームアップ期間）ときは `null` を返し、その項目を正規化の分母から外す。

### c_trend — トレンド (20)

| 条件 | 点 |
|---|---:|
| 終値 > SMA25 | 5 |
| 終値 > SMA75 | 5 |
| SMA25 が上向き（前日比 > 0） | 5 |
| SMA75 が上向き（前日比 > 0） | 5 |

### c_rsi — RSI14 (10)

RSI は「高いほど良い」ではない。買われすぎは減点する。

| RSI14 | 点 |
|---|---:|
| 50 以上 65 未満 | 10 |
| 65 以上 70 未満 | 8 |
| 45 以上 50 未満 | 7 |
| 40 以上 45 未満 | 5 |
| 70 以上 80 未満 | 4 |
| 30 以上 40 未満 | 3 |
| 80 以上 | 1 |
| 30 未満 | 2 |

### c_macd — MACD(12,26,9) (15)

| 条件 | 点 |
|---|---:|
| MACD > Signal | 6 |
| Histogram > 0 | 4 |
| Histogram が前日より拡大 | 3 |
| MACD > 0（ゼロライン上） | 2 |

### c_ma — 移動平均の並び (15)

| 条件 | 点 |
|---|---:|
| SMA5 > SMA25（短期が上） | 5 |
| SMA25 > SMA75 | 5 |
| 終値 > SMA200（長期トレンド上） | 3 |
| SMA5 が上向き | 2 |

### c_volume — 出来高 (10)

`vol_ratio = volume / SMA20(volume)`

**移動平均は当日を含む 20 本**（`indicators_daily.vol_sma20` と同じ値）。
当日を除く流儀もあるが、保存している列と定義を一致させるほうを取った。
当日を含めるぶん比率はやや小さく出るので、閾値はそれ込みで決めてある。

| vol_ratio | 点 |
|---|---:|
| 1.5 以上 3.0 未満 | 10 |
| 1.2 以上 1.5 未満 | 8 |
| 3.0 以上 | 6 |
| 0.8 以上 1.2 未満 | 4 |
| 0.8 未満 | 1 |

**3.0 以上を満点にしない。** 出来高が平常の 3 倍を超える日は、
上昇でも急落でも起きる。単独では強気の材料にならない。

### c_momentum — モメンタム (10)

| 条件 | 点 |
|---|---:|
| 20 営業日リターン > 0 | 3 |
| 60 営業日リターン > 0 | 3 |
| 終値が 52 週高値の 90% 以上 | 4 |

### c_fundamental — ファンダメンタル (10) — Phase 1b

`fundamentals` の **`disclosed_at <= 評価日`** の最新行のみを使う。
決算期（`fiscal_period`）で引かない。未公表の決算を使ったら検証が無意味になる。

### c_news — ニュース (10) — Phase 1b

直近 5 営業日の `news_symbols` から算出。重要度 S/A のみを対象にする。

## verdict（4 段階）

`total` だけで決めない。**スコアが高くても入り口が悪ければ `BUY_WATCH` にする。**

| verdict | 条件 |
|---|---|
| `BUY_NOW` | `total >= 75` かつ `c_macd >= 10` かつ `rsi14 < 70` かつ `vol_ratio >= 1.0` |
| `BUY_WATCH` | `total >= 60`（`BUY_NOW` に届かないもの） |
| `WATCH` | `total >= 40` |
| `AVOID` | それ以外、または終値 < SMA75 かつ SMA25 が下向き |

> **Phase 5（バックテスト）が終わるまで、画面で `BUY_NOW` を「推奨」と表示しない。**
> スコアは「条件への合致度」であって「期待リターン」ではない。

## エントリー / 損切り / 利確

予測はしない。ATR14 を使って**機械的に**決める。

```
entry_px  = 終値                       （翌営業日の寄りで約定する想定）
stop_px   = 終値 - 2.0 × ATR14         （SMA25 を下回る場合は SMA25 の少し下を優先）
target_px = 終値 + 3.0 × ATR14
rr        = (target_px - entry_px) / (entry_px - stop_px)   ≒ 1.5
```

ATR ベースにするのは、値幅の大きい銘柄と小さい銘柄で同じ「-7%」を当てても
意味が違うため。`rr` が 1.2 を下回る組み合わせは `BUY_NOW` から外す。
