# LP 制作ブリーフ

公開 LP（先行登録ページ）をデザインする人向けの仕様。
**コードを読まずにここだけで判断できる**ことを目指している。

実物は `npm run dev` → `http://localhost:8787/lp`。

---

## 何のためのページか

| | |
|---|---|
| 目的 | 先行登録（メールアドレスの取得）1 つだけ |
| 読み手 | 個人投資家。株式スクリーナーを使ったことがある層 |
| 置き場所 | 独自ドメインの `/`（公開）。ダッシュボードは別サブドメインで Access の後ろ |
| **出してはいけないもの** | **銘柄名・価格・スコア・ランキングなど市場データを一切載せない** |

最後の 1 行は見た目の都合ではなく、市場データの提供元との取り決めが
未確認だという事情による（`DATA-SOURCES.md`）。
実データのスクリーンショットも同じ理由で置けない。

---

## 節の構成と役割

| # | 節 | 役割 | 落とせるか |
|---|---|---|---|
| 1 | ヒーロー | 一文で何をするかを言い、その場で登録させる | 落とせない |
| 2 | やっていること | 3 ステップ。機械的に計算する / 条件を重ねて絞る / 根拠ごと出す | 落とせない |
| 3 | **やらないこと** | 4 項目。ここが差別化そのもの | **落とせない** |
| 4 | いまの状態 | どこまで動いていて、何がこれからか | 統合可 |
| 5 | 先行登録 | ヒーローと同じフォームを再掲 | 落とせない |
| 6 | フッター | 免責・運営者・プライバシーポリシー | 落とせない |

3 の「やらないこと」を装飾で弱めないこと。
よくあるスクリーナーとの違いはここにしかない。

## 書いてはいけない表現

金融商品取引法と景品表示法の両方に触れうるので、**表現は見た目より優先する。**

| 禁止 | 代わりに |
|---|---|
| 儲かる / 稼げる / 勝てる | （書かない） |
| 推奨銘柄 / おすすめ銘柄 | 条件に合致した候補 |
| 予測 / 予想（株価について） | 条件への合致度 |
| 必ず / 確実に / 高確率で | （書かない） |
| スコア = 期待リターン | スコアは条件への合致度であって、何 % 上がるかを表す数字ではない |

**「AI が銘柄を当てる」と読める表現にしない。** AI の役割はニュースの
分類・要約・説明に限る、というのがこのシステムの設計そのもの。

## 必ず画面に出るもの

- **免責**（フッター。本文を削らない）
  > 本サービスは情報提供および投資判断の支援を目的としたものであり、特定の銘柄の売買を勧誘するものではありません。……投資判断はご自身の責任で行ってください。
- 同意チェックボックス（フォーム内。**チェック必須**）
- プライバシーポリシーへの導線
- 運営者名・問い合わせ先（現在は角括弧の未記入。**埋めずに公開しない**）

## フォームの仕様

| 項目 | |
|---|---|
| `email` | `type="email"`、`required`、最大 254 文字 |
| `consent` | チェックボックス、`required`。同意した時刻を保存する |
| `company` | **ハニーポット。人には見えない位置に置く**（`left: -9999px`）。`display:none` にしない — 自動投稿に気づかれる |
| `source` | hidden。流入元の識別 |

送信先は同一オリジンの `POST /api/waitlist`。
JavaScript 無しで動く（フォーム送信でページが返る）ので、**JS 前提の
送信処理に置き換えないこと。**

## 見た目の決まり

| | |
|---|---|
| 配色 | `packages/worker/src/ui/tokens.ts` が唯一の定義。役割名（`--accent` など）で参照する |
| 明暗 | `prefers-color-scheme` の両方に対応する。片方だけ作らない |
| 本文幅 | `--maxw`（現在 720px） |
| タップ領域 | **最小 44px**。現在の入力欄とボタンは 48px |
| 書体 | `FONT_STACK`（和文が読める順）。Web フォントを足すなら読み込み方法ごと決める |
| 画像 | 現在ゼロ。足すなら Worker のバンドルに載るサイズか、R2 配信かを決める |

## テンプレートを当てるときに触るファイル

| ファイル | 何を差し替えるか |
|---|---|
| `packages/worker/src/ui/tokens.ts` | 配色。**ここ 1 つでアプリ側にも反映される** |
| `packages/worker/src/ui/lp.ts` の `STYLES` | LP のレイアウトと装飾 |
| `packages/worker/src/ui/lp.ts` の各節 | マークアップ。**本文（コピー）はそのまま流用できる** |

`tokens.ts` 以外の場所でパレットを再定義すると `npm test` が落ちる
（`test/tokens.test.mjs`）。LP とダッシュボードで色がずれるのを防ぐため。

---

## 確認の手順

```bash
npm test                    # 表現と構造の検査を含む
npm run dev                 # /lp を開く
```

テストが検査していること（デザイン変更で壊しやすい順）:

- 免責が出ている
- 銘柄名・価格・`BUY_NOW` が LP に出ていない
- ハニーポットが画面外に置かれている
- 同意なしでは登録できない
- LP とダッシュボードが同じパレットを配信している

描画は**デスクトップ・モバイル・ダークの 3 つで必ず見ること。**
前回この確認で、見出しだけ左端に寄る不具合と、日本語の文中に
余分な空白が入る不具合を検出している。
